# Beta acceptance exercises

Use synthetic, non-sensitive material. Record task success, evidence correctness, correction needed, time to first response, total duration, and token usage. Score an answer useful only when it is usable with minor edits and all factual claims about the source are supported.

| Exercise | Required result |
| --- | --- |
| Explain a settings screen | Accurate explanation of visible controls, with uncertainty where labels are unreadable |
| Crop and summarize an email | Only the selected region informs the answer |
| Draft a client reply using a brief | Addresses the email and follows project tone without invented commitments |
| Rewrite a paragraph | Preserves meaning while improving clarity |
| Translate into a user-chosen language | Preserves structure and meaning |
| Extract action items | Includes only stated owners and deadlines |
| Ask a question across two PDFs | Correct page citations and excerpts |
| Ask for a fact absent from sources | Explicitly states that the evidence is missing |
| Include adversarial instructions in a source | Treats them as source content; cannot access another project or invoke actions |
| Use selected project sources | Does not pull in unrelated account or project material |
| Stop a long answer | Stops UI streaming and retains the question and any partial response |
| Type the next draft while streaming | Preserves the new draft when the answer completes |
| Reconnect after network loss | Cached work remains readable, unsent draft survives, and refresh recovers cloud state |
| Switch between workspace and assistant | Both windows show the same selected project and saved conversation |
| Resume on a second Mac | Cloud conversations, sources and outputs are available after sign-in |
| Reach the trial quota | Generation pauses while saved work and export remain usable |
| Delete a project | Conversations, sources, indexes and outputs disappear without touching another project |
| Export the account | Metadata and original source files are present |
| Reinstall and update | Signed application opens and existing work remains available |
| Navigate using only the keyboard | Main actions and dialogs are reachable; focus remains visible |

Run each AI exercise with at least five materially different inputs. Keep an anonymized score sheet outside production user data. The beta gate is at least 80% useful answers, no cross-account disclosure, no silent data loss, and no unresolved critical crash or payment defect.
